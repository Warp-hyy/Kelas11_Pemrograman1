# Brother John & Sons – Website Kuliner

Website sederhana bertema kuliner untuk **Brother John & Sons**, merek gourmet burger artisan lokal asal Bandung. Dibuat dengan HTML, CSS, dan JavaScript terpisah untuk tugas praktikum.

## Fitur
- Navigasi sticky dan tampilan responsif (desktop dan mobile).
- Hero dengan animasi burger.
- Daftar menu: The 1984 Cheese Burger, Boss of The Buns, side dish, minuman.

## Interaksi JavaScript
1. **Filter menu** berdasarkan kategori (Semua, Burger, Side dish, Minuman).
2. **Keranjang pesanan**: tambah, kurangi, hitung total otomatis, dan checkout.
3. **Menu hamburger** pada tampilan mobile.
4. **Validasi form reservasi** (nama, nomor HP, tanggal, jumlah orang).

## Cara Menjalankan
Buka `index.html` di browser. Tidak perlu instalasi.

## Catatan
- Harga dan deskripsi menu selain dua burger andalan adalah **data contoh** dan bisa diganti di array `MENU` pada `script.js`.
- Penggunaan AI: kode dibuat dengan bantuan Claude memakai prompt terstruktur (Role, Task, Context, Reasoning, Stop conditions, Output), lalu dipelajari dan disesuaikan sendiri.
