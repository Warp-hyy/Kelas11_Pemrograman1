## 3 Fitur Interaksi JavaScript
1. **Dark Mode Toggle (Mode Gelap/Terang):**  
   Pengguna dapat mengubah skema warna website secara langsung dengan tombol di navigasi. Sistem memanipulasi class CSS pada elemen `body` secara dinamis.
2. **Filter Kategori Menu:**  
   Menyaring tampilan daftar menu secara instan berdasarkan kategori ("Semua", "Makanan", atau "Minuman") menggunakan atribut data (`data-category`).
3. **Kalkulator Keranjang Pesanan Interaktif:**  
   Menghitung akumulasi jumlah pesanan dan total harga tagihan (format Rupiah) secara *real-time* saat tombol "+ Tambah" diklik, lengkap dengan fitur reset dan tombol bayar/checkout.
