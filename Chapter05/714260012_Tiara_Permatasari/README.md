## Deskripsi Website

Website ini dibuat untuk memenuhi Tugas Chapter 05.
[News Portal / Expense Tracker] adalah website yang dibuat
menggunakan HTML, CSS, dan JavaScript.

Website ini memiliki tampilan responsif yang dapat dibuka
di laptop maupun HP, dilengkapi dengan navigasi dan
fitur interaktif berbasis JavaScript.

## Fitur Website

1.  **Navigasi** - Navbar yang memudahkan pindah antar halaman / section.
2.  **Tampilan Responsif** - Layout menyesuaikan ukuran layar (desktop, tablet, HP).
3.  **Fitur JavaScript 1:** [Contoh: Dark Mode / Pencarian Berita]
4.  **Fitur JavaScript 2:** [Contoh: Filter Kategori / Tambah Pengeluaran]
5.  **Fitur JavaScript 3:** [Contoh: Bookmark / Hitung Total Otomatis]
