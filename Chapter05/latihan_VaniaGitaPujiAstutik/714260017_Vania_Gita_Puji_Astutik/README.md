## Deskripsi Website
Explore Pacitan merupakan website sederhana
yang dibuat untuk memperkenalkan berbagai
destinasi wisata di Kabupaten Pacitan,
Jawa Timur.

Website ini menampilkan informasi wisata
pantai, goa, dan sungai.

## Teknologi
- HTML
- CSS
- JavaScript

## Fitur Website
1. Navigasi website
2. Pencarian tempat wisata
3. Filter kategori wisata
4. Detail informasi wisata
5. Tombol lokasi Google Maps
6. Tombol kembali ke atas

## Cara Menjalankan
1. Buka folder project di Visual Studio Code.
2. Buka file index.html.
3. Klik kanan.
4. Pilih Open with Live Server.
